# Demo clips

`demo/audio/S1.wav`, `S2.wav`, `S3.wav` are **synthetic**: generated by `python scripts/synthesize_demo_clips.py`
from the matching file in `demo/transcripts/` using Bulbul text-to-speech, one voice per clip.
They are not real clinic audio and are cleaner than a real microphone recording, so STT scores measured on them
are optimistic. Replace them with fake-patient recordings (same filenames) for a fair measurement.

`demo/audio/mock.wav` is a generated tone used only by MOCK_MODE for summary and alert playback.

The files in `demo/transcripts/` are the exact text spoken in each clip (the reference for `scripts/compare_stt.py`).
Fake patients only.
